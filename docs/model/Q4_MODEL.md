# Q4动态电价模型（候选）

题面第4题要求在波动电价下重算第2、3题。本版保持[Q2/Q3模型与反馈](../experiments/Q23_REAL_RESULTS.md)，把固定日内价格p[t]替换为每日目标槽价格p[d,t]。

## 信息集

显式假设当日整条价格曲线在当天零点可知，当前日实际负荷/PV仍不可预先读取。程序仅在价格政策为 `full_target_day_price_curve_known_at_midnight_candidate` 时接入；附件4本身不证明提前可知。若采用仅实时已知的解释，本版不能直接作为该解释的无泄漏方案。

## 目标及结算

Q4-2日前目标为 `min sum(p[d,t]*G[d,t])`，代入当时的负荷/PV预测及储能约束。实际费用为计划量价积加 `sum(5*p[d,t]*U[d,t])`。

Q4-3在6/12/18点以真实SOC、当次已发布PV与当前承诺g重规划，只改变当天未执行槽。每次调整费用为：

`sum(p[d,t]*(1.5*max(G_new-g,0)-0.5*max(g-G_new,0)))`。

总费用为零点原计划费、逐次调整净费用、实际应急费三者之和。取消按该目标槽原价退回并收半价罚金，增加量按该目标槽1.5倍价结算。同一目标槽的p[d,t]在各次更新中保持一致；本版没有引入随成交批次变化的合同价，也没有把更新时刻单个价格用于整个剩余日。

充放电、能量平衡和日终可达性均复用原内核。仍采用单向0.9、母线侧5000 kW、1200—10800 kWh、日终6000的候选参数。每个确定性预测问题的最优不等于实际全年随机控制最优。

## 比较与实现

[真实实验](../experiments/Q4_REAL_RESULTS.md)含动态价日前、仅零点PV、三次旧PV控制、三次新PV四组策略，以及固定原Q2/Q3动作在动态价下重计价控制。后者用于区分价格环境变化与重新优化动作的作用。

入口 `scripts/run_real_q4.py` 复用 `execute_day`、`replan` 与 `CausalExecutor`；价格加载器只做验证和分组，不清洗或改写CSV。最终验收仍需确认价格与时间语义。
