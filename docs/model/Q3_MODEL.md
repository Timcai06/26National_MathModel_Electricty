# Q3滚动购电模型（候选）

完整假设、推导口径与真实证据见[Q2/Q3报告](../experiments/Q23_REAL_RESULTS.md)。实现入口为 `src/q3/pv.py`、`src/q3/planning.py`、`scripts/run_real_q23.py`。

对每次决策时刻，剩余槽使用预测负荷L、当次已发布并积分转换的PV；变量G为新承诺，C/D为母线侧充放电，W为无收益富余，E为储能。

约束沿用[公共内核](MICROGRID_CORE.md)：

- `G + PV + D = L + C + W`；计划阶段不引入可随意使用的未来真实紧急购电。
- `E[t+1] = E[t] + 0.9*C[t] - D[t]/0.9`。
- `1200 <= E <= 10800`，`0 <= C,D <= 5000/6`；G/W非负，C/D同槽互斥。
- 决策起点E等于实际执行状态；候选日末E=6000。已执行槽不可修改。

0点最小化 `sum(p*G)`，保存初始合同。6/12/18点相对当前承诺g逐次优化：

`min sum(0.5*p*G + p*z - 0.5*p*g)`，其中 `z >= G-g`、`z >= 0`。

该凸分段目标精确表示增加量1.5倍价、取消量退原价后收半价罚金的净费用。LP结果有同槽充放电时重解MILP；成功后另用实际正负差核对目标。备选不退款解释为 `min sum(-0.5*p*G + 2*p*z + 0.5*p*g)`。

执行器只接收当前槽观测，实际不足以5倍电价应急购买，并维护日终可达性。滚动优化不读取未来实际数据，不提前交易次日合同；PV转换不使用未来实际值填h=0。

所有阶段实测结果中的“最优”只指当次确定性预测问题求解最优。实际全年策略是带假设的确定性滚动策略，不是全知或随机最优控制。实际费用必须从原合同、每次调整和应急购买重新结算，不能将新计划目标值相加。

第3题固定更新组合与旧预报控制实验已完成；根据实时预期收益选择是否更新的自适应VOI尚未实现。输出时间标签、观测和退费解释仍待最终语义验收。
