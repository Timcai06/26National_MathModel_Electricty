## 时间与信息索引

- $d$：模型日；$t=0,\ldots,143$：该日动作槽，内部字段为 `slot_id`。
- $k=0,\ldots,144$：储电量状态边界。一日有 144 组动作、145 个储能状态。
- $\Delta t=1/6$ 小时。实际 `start_time/end_time` 由时间映射决定，不由槽号直接拼字符串。
- $r$：预测发布时间或滚动决策时刻；$\widehat L_{d,t\mid r}$、$\widehat V_{d,t\mid r}$：在 $r$ 已知信息下的预测。实际值用 $L^{act},V^{act}$，不得混用。
- 附件 3 的预报步长 $h=1,\ldots,24$；原始目标时刻为发布时间加 $h$ 小时，跨日保留完整日期。转成 10 分钟槽仍需插值与时间语义契约。

## 变量字典

以下电量均为每槽 kWh，储电量为边界时刻的 kWh；价格为元/kWh。

| 符号 | 接口字段示例 | 含义 |
| --- | --- | --- |
| $L_t$ | `load_kwh` | 槽内负载电量 |
| $V_t$ | `pv_kwh` | 槽内可用光伏电量，必须标明 forecast/actual |
| $G_t^0$ | `planned_purchase_kwh` | 0:00 提交的初始购电承诺 |
| $G_t^{r}$ | `committed_purchase_kwh` | 最近一次允许调整后，该槽的购电承诺；Q1/Q2 等于 $G_t^0$ |
| $U_t$ | `emergency_purchase_kwh` | 执行时的紧急购电 |
| $C_t$ | `charge_bus_kwh` | 从微网母线流入充电设备的电量 |
| $D_t$ | `discharge_bus_kwh` | 储能向母线交付的电量，已经过放电损耗 |
| $E_k$ | `stored_energy_kwh` | 电池内部储电量 |
| $s_k$ | `soc_fraction` | $E_k/12000$，无量纲，范围 0.1–0.9 |
| $W_t$ | `surplus_kwh` | 未被负载或储能使用的富余电量，非售电收益 |
| $p_t$ | `price_yuan_per_kwh` | 槽位电价；动态价格场景另标可用时刻 |
| $\eta_c,\eta_d$ | `charge_efficiency`, `discharge_efficiency` | 充电输入到电池、放电电池到母线的效率 |

`E` 表示 kWh，`soc_fraction` 表示比例，禁止用同一个含糊的 `soc` 参数传入两种单位。`C/D` 也不等于电池内部增减电量。

## 单位规则

按槽内代表功率解释原始 kW 后，由适配层一次转换：

\[
L_t=P^L_t\Delta t,\qquad V_t=P^{PV}_t\Delta t,\qquad p_tG_t\text{ 的单位为元}.
\]

原始功率是否可视为区间均值是时间契约的一部分。优化层只接收 kWh，不再除以 6。累计电量求和，不能对已转换 kWh 再乘时间长度。

采用母线侧功率上限的候选解释时：

\[
0\le C_t,D_t\le 5000/6=833.333333\ldots\text{ kWh}.
\]

计算保留精度，最后写结果时才按交付契约舍入。

## 储能与能量平衡推导

在效率候选 $\eta_c=\eta_d=0.9$ 下：

\[
E_{t+1}=E_t+\eta_c C_t-D_t/\eta_d,\quad 1200\le E_k\le10800.
\]

充入母线侧 100 kWh，电池增加 90 kWh；向母线放出 90 kWh，电池减少 100 kWh。充放一轮往返效率是 0.81，不是 0.9；这是单向效率解释的结果，不能冒充题面明确给出的往返效率。

公共母线平衡为：

\[
G_t^r+V_t+D_t+U_t=L_t+C_t+W_t,
\qquad G_t^r,C_t,D_t,U_t,W_t\ge0.
\]

- Q1 采用给定预测和负载，设置 $U_t=0$。目标为 $\min\sum_t p_tG_t^0$。
- Q2–Q4 规划时使用当时可用预测；实际执行账本换为实际负载/光伏与实际充放电，不把预测方程当执行结果。
- Q1 必须 $E_{144}=E_0$；年度模拟首状态为 6000，之后每天起点继承前一天终点。日中性是附加约束，不是重置操作。
- $W_t$ 暂表示一般富余，允许包含已经付费的过量计划购电；若只统计弃光，应另建有 $W_t^{PV}\le V_t$ 的弃光归因，不能把所有 $W_t$ 直接称为弃光。
- 不设外网售电变量；这是无售电规则和收益信息下的候选建模假设。

物理上应避免同时充放电。按源计划先检验 LP 松弛；只有实际解满足互斥才接收，否则启用 $z_t\in\{0,1\}$、$C_t\le\bar C z_t$、$D_t\le\bar D(1-z_t)$。不能把“先用 LP”写成已证明松弛必然精确。
