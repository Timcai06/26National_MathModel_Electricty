## 共用数据接口

数据流保持为：原始 Excel → 数据适配层 → 标准数据对象 → 优化内核。核心优化器不自行解析 Excel。

以下是待 Phase 0 冻结的字段草案，不是已验证的数据契约：

| 对象 | 至少包含 | 关键约束 |
| --- | --- | --- |
| 时间映射 | `slot_id`、原始文件/sheet/列、官方展示标签、模型起止时刻、跨日标识、输出列 | `slot_id=0..143` 只是位置；不能从示例推断首槽物理含义 |
| 日内/全年负载与光伏 | `date`、`slot_id`、`load_kw`、`load_kwh`、带 actual/forecast 含义的 PV 字段 | 原功率和派生电量分别保留；10 分钟槽按一次 `P/6` 转换 |
| 预测发布记录 | 完整 `issue_time`、完整 `target_time`、`forecast_horizon`、`pv_forecast_kw`、来源位置 | 日期跨日明确；决策时只取已发布且目标属于待决策时段的数据 |
| 动态价格 | `date`、`slot_id`、`price`、价格单位/可知性说明 | 不能仅按行号跨日期拼接；真实价格可用性属于模型假设 |

协作源文档的 `slot` 统一映射为内部 `slot_id`，在数据字典记录别名；保留官方标签，不修改原始文件。小时 PV 转为 10 分钟采用哪种方法、小时值代表整点还是区间，均需明确。B 做误差统计必须使用同一时间含义、同一功率或电量粒度，不直接把小时预测与任一 10 分钟实测相减。

## 冲突处理

1. **立即开发与 Gate 0**：准备工作并行，真实数据正式求解仍按 Gate 推进；不把“无等待”解释成无需数据核验。
2. **固定时间示例与官方列语义**：示例只作候选解释，由真实输入和模板逐列核验后冻结。
3. **Phase 0 成本比较与禁止求解**：Phase 0 保留 SOC 双解释和两种 PV 转换的实验协议；正式比较依赖内核和回测，记录为后续实验。它不替代 Gate 0 的数据检查；当前五份模板已找到，但时间/输出映射与数据测试仍需证据。
4. **B 不等 A**：B 先独立检查原始输入，随后对 A 的输出交叉检查；统计和误差表只在相关映射可用后生成。

上述为本次对两份源方案的执行解释；如果 tim 调整顺序或边界，在此与任务板同步记录，不悄悄改写源计划。
