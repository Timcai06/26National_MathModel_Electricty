## 结构性结论：应急电量与电价无关

固定承诺加B0控制器时，应急与富余轨迹**完全不随电价改变**。对334天逐槽比较固定电价B2与动态电价B2：

| 量 | 两次运行的逐槽最大差 |
| --- | ---: |
| 应急电量 $U_t$ | $2.2\times10^{-8}$ kWh |
| 无收益富余 $W_t$ | $2.2\times10^{-8}$ kWh |
| $C_t-G_t-D_t$ | $2.2\times10^{-8}$ kWh |
| 充电量 $C_t$ | 833.333 kWh（满槽功率） |

机制是：日前线性规划在最优解处不产生富余，故 $G=\widehat L+\widehat C-\widehat V-\widehat D$；B0执行器照搬计划的电池动作，于是槽末缺口

$$U_t=\big[(L_t-\widehat L_t)-(V_t-\widehat V_t)\big]_+$$

只由净负荷预测误差决定。电价改变的是计划在时间上的分配和电池循环量，**承诺量同步吸收了电池动作的变化**，因此外网需要补的残差不变。推论有二：一是安全裕量的作用对象（预测误差）与价格无关，所以它能零成本迁移；二是在动态电价下讨论"降低应急电量"必须改动预测或控制律，单靠改价格做不到。该断言由复核脚本机器检查，不作为文字主张。

## 价格可知性的价值

对照组"按固定代表日电价制定计划、按真实动态电价结算"：总费15,967,316.98元，比真正使用动态曲线的15,829,022.52元高138,294.46元，即0.8661%。两者应急电量同为380,769.33 kWh，印证上节结论——**这0.87%完全来自计划购电在时间上的重新分配，与应急无关**。

这也界定了"价格提前可知"这一条件假设的影响上限：即使完全不知道当天价格形状而沿用一条固定曲线，损失也不到1%。因此该假设虽未验收，对结论的威胁有限。
