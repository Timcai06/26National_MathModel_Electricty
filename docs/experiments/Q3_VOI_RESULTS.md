# Q3预期净收益门控：一月冻结与全年结果

日期：2026-09-11。门控实现及334天回放完成，85条一月开发轨迹、334条正式日轨迹、1257次门控独立复核通过。原始数据、固定策略结果与五份候选Excel未修改。

## 结论

| --- | ---: | ---: | ---: | ---: |

门控相对固定更新节省561,111.20元（3.5777%），但相对更强的裕量零点固定仅节省 **7,355.33元（0.0486%）**。新增调整费220,775.53元，几乎抵消了应急费减少的228,130.86元。

因此，本轮完成了可执行的门控，但不将它替换为主方案：增益低于此前0.25%的复杂度参考线，且四个月费用上升。该参考是工程取舍，并非题目要求或统计定理。保留门控为消融/选择性更新实验，主方案继续采用更简单的裕量零点固定，不以战胜较差的固定更新包装成显著新增优化。

1002次更新机会中接受183次，均为实质合同变化，覆盖167天；其余机会保持当前合同及控制预测。全年相对零点固定95天更省、72天更贵、167天基本持平（1e-5元容差）。

## 门控的具体口径

每个6/12/18点先用该时点已发布的新PV提出新合同，再从同一当前SOC复制两个执行状态：

- keep：合同、储能控制使用的预测均保留当前版本。
- update：采纳当前新PV和候选合同，其余仍沿用已冻结的负荷裕量。

两条预演均使用严格槽首贪心储能，保持日终6000、功率和能量约束；假设这次选择以后合同保持到午夜。真实执行到下一个更新时刻时再重新估值。这是重复的一步前瞻近似，不是假装已经知道后续发布预报的多阶段最优控制。

已有普通购电与此前调整成本在当前决策中已确定，因此只比较剩余可变费用：keep的预期5倍应急费，以及update的立即调整费加预期5倍应急费。调整费只计一次，不再叠加一遍未来普通购电账本。可能出现负净调整费，保留其退款含义。

仅当 `predicted_keep − predicted_update > threshold + 1e-6元` 才更新；额外1e-6是避免浮点微差触发更新的数值容差，不是另一个调参指标。

## 联合历史场景

固定取过去28天内最近20个符合条件的完整日，等权，每次至少7日；不足时保持当前策略。没有逐槽独立抽样，也没有在正式期调整窗口或样本数。

对历史日d，在与当前决策相同的6/12/18发布时间，使用：

- 负荷残差：历史实际负荷减去当时可用的上周同时刻负荷。
- PV残差：历史实际PV减去该历史日对应发布时间的线性积分PV预报。

同一历史日的两条剩余日残差路径一起加入目标日“未加裕量的上周负荷＋当前发布PV”点预测，作为一条场景。保持日内及负荷/PV配对结构；物理上不可能的负场景电量截为0，并记录截断数量。此处截断的是模拟场景，不修改源数据。

当前日实际值不进入场景库。历史实际日必须在目标日零点前完整发布，历史负荷预测源必须在历史日零点可用；传入的预报映射拒绝未来发布时间。keep/update共用完全相同的场景数组及权重。

因为固定储能动作下实际净负荷只影响应急/富余结算，两条储能路径只需各预演一次，再向量化计算各场景费用。这不是为每条完整场景独立选择一套预知未来的电池动作。

## 一月参数选择

保持Q2已选的裕量参数，门控额外比较关闭更新与0/100/500/1000元阈值。只用1月15—31日17天开发回放选型，每个决策的残差库仍仅包含当时已完整发布的历史日。选择函数仅接收一月实际值和一月预报。

| 配置 | 一月费用（元） | 接受更新次数 |
| --- | ---: | ---: |
| 不更新 | 948,291.73 | 0 |
| 阈值0元 | 927,279.21 | 25 |
| 阈值100元 | 927,343.81 | 22 |
| **阈值500元** | **927,163.16** | **11** |

500元阈值在一月选中，配置在正式评价前落盘并记录哈希；2—12月未再调参。0元与500元开发费用差距很小，本轮不据全年表现重新挑选其他阈值。已经看过全年旧基线，仍称回顾性固定回放，不称独立盲测。
