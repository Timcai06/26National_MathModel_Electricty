## 共同协议与初始化

题面来源：[C题.pdf](../../CUMCM2026Problems/C题/C题.pdf)第1—3页。正式输出与评价为2025-02-01至12-31，共334天，每策略48096槽。附件1电价每天重复；附件2实测用于已发生历史与事后结算；第3题另用附件3已发布预报。三个源CSV均核对接收审计SHA，运行前后不变。原始清洗数据未改写。

- 电池容量12000 kWh，允许储电1200—10800 kWh，母线侧充/放功率各不超过5000 kW；单向效率各0.9。
- 每日目标储电6000 kWh，实际前日末状态传入次日，不在2月1日人为重置。该日中性约束是候选建模选择；Q2/Q3题面没有明确要求每天回到6000。
- 完整日数据假设次日零点可用；当前槽能量假设在槽结算边界可知并用于该槽储能反馈。这是离散仿真假设，不是从CSV观测出的发布时间，也不等于真实控制系统已验证。
- 外网富余没有售电收益。应急购电按当前槽电价5倍计费；允许为满足终端储能目标而应急充电。

1月1日00:00由题面6000 kWh开始。由于没有2024年历史，1月1日使用零计划承诺、储能与紧急购电的因果补救作为显式冷启动；1月2—31日用昨日负荷/PV基线计划与同一执行器。两题所有正式比较共享这一实际执行的1月路径，1月费用2942592.499286元单独报告，不混入2—12月评价。该冷启动策略保守且成本高，仅用于无历史条件下的可复现初始化，不是预测出来的零负荷，也不声称1月最优。

## 第2题：预测、计划与实际执行

只用1月8—31日比较昨日与上周同时刻的逐槽MAE，2月1日冻结各变量方法：负荷取上周同时刻，光伏取昨日同时刻。1月MAE分别为：负荷昨日109.109665、上周23.882642；光伏昨日18.800086、上周21.418554，单位kWh/槽。选择程序未用2—12月指标或费用选取主预测方法。此前探索已查看全年两条基线误差，因此本次属于回溯实验，不声称是预注册盲测。

每天0点，以预测负荷与PV代入公共能量平衡和储能状态方程，最小化预测下的计划费用 `sum(p[t]*G[t])`。求解先LP，出现同槽充放电时重新解MILP；只有独立物理校验通过的最优求解才提供计划。该日前优化不接收目标日实际曲线。

实际执行保持购电承诺G固定。每槽以当前净富余优先充电、净缺口优先放电；下一状态投影到电量/功率限制以及日终6000可达的区间，剩余缺口记为紧急购电U，富余记为W。日前优化费用与实际费用严格区分：

`J2 = sum(p*G) + sum(5*p*U)`。

这是确定性计划加因果反馈的基础策略，不是随机最优控制或全年事后全知最优。所有比较使用同一反馈规则和相同边界储能。

## 第3题：预报转换与滚动模型

### 预报转换

[转换模块](../../src/q3/pv.py)逐组校验365×4×24条小时预报，保留发布时刻、目标时刻与跨年预测。输出[10分钟候选表](../../data/derived/pv_10min_candidate.csv)含210240行，每行同时给出线性和常数两种能量结果；两版使用相同原预报，不读取任何目标日实测来补预报。

主版将整点功率视作瞬时预测，整点间分段线性，在每个10分钟物理区间积分得到kWh；由于没有h=0，发布后首小时保持第1小时预测值。梯形积分在该分段线性曲线上是精确积分，而不是直接把单个边界功率乘1/6。对照版每小时保持对应h=1…24预测值，平均分为6槽。首小时、末端和跨日边界均显式定义，禁止未来实测回填。跨至2026年的预报保留，但当前模型只交易当日剩余槽，不评价不存在的2026年实测。

### 调整及账务

0点用当次光伏预报与冻结负荷方法制定初始承诺。6、12、18点以已经执行到当前的真实SOC为起点，用当次新预报重算当天剩余时段。已经发生的槽不可修改，也不提前修改次日合同。

主解释：取消的原合同金额退回，再收50%违约金；增加量按1.5倍槽位电价结算。每次相对“当前承诺”调整，而非反复相对0点计划：

`delta = G_new - G_old`

`adjustment = sum(p * (1.5*max(delta,0) - 0.5*max(-delta,0)))`

`J3 = initial_plan_cost + sum(each adjustment) + emergency_cost`。

优化使用凸分段线性费用：引入 `z >= G_new-G_old`、`z >= 0`，最小化 `sum(0.5*p*G_new + p*z - 0.5*p*G_old)`；没有可以无限退款的自由负变量。每次求解后独立计算真实正负差和费用，并检查储能互斥。退款账本另与“最终承诺原价 + 逐次增减各半价罚金”核对一致。

“不退原价、另收取消罚金”也完成整期敏感性计算，对应成本斜率为负0.5p和正1.5p。该解释下保留已付款富余可能比付费取消更经济。不能因为它在当前反馈策略中费用更低就据此认定其是正确题意。

## 是否需要其他时刻的预报

在该样本与主假设下，分别在6、12、18点更新均比完全不更新费用低，三次更新总费用最低（指同一主计费/线性转换下的预先列出的更新组合）。单次18点更新节省最多，但这包含了重新观测SOC、修正此前预测误差和避免日终高价应急恢复的作用，不能全部算为晚间新光伏信息的价值。

控制这一区别后：同样三次按实际SOC重规划而一直沿用零点预报，费用为13983971.999418元；换用新发布预报后为13932761.588874元，新预报在这一对照下进一步节省51210.410544元，约0.3662%。因此数据支持“滚动重规划有明显价值，新预报在三次更新组合中有额外价值”；尚不能断言每个时刻的新预报单独都有正的信息价值，更没有证明每一天每次更新都值得。自适应VOI开关属于后续增强。

线性与常数转换会显著影响费用，常数版总费用16079237.923196元；两种转换的选择需要在论文中解释物理含义，不能隐去敏感性。主线沿用计算前指定的线性积分方案。
