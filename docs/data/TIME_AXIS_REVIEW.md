# 封版前时间语义复核：时点、时段与模板

2026-09-11。tim指出10分钟时段与附件时点的差异。本轮重新读取题面原PDF、渲染第1—2页，读取原附件1及result1/result2表头，对照现有时间轴和读取代码。未修改源数据、模板、求解器或已有结果。

## 已核实的事实

1. 题面附录2说明附件1/2给出不同时间的负荷与PV功率，单位kW；未明确将各点声明为前10分钟平均功率。附录5要求填写10分钟购电量，单位kWh。
2. 输入时间从00:10到0:00+1，共144点；题面明确0:00+1等于本日24:00，不是本日0:00。
3. 题面表1包括10:00—10:10；表2覆盖00:00—24:00，Q1要求0与24点SOC相等。
4. 原result1购电表首行为00:10—00:20，末行为次日00:00—00:10。年度模板首列相同，末列写作`0:00-0:10+1`，存在日偏移表达不一致。

因此，时点/时段区别和模板覆盖范围是两个独立问题，不能用“乘1/6即可”或“整体移一列”同时解决。

## 当前代码的候选解释

`scripts/run_real_q2_forecast.py` 校验加工CSV满足kWh=kW/6，按终点序列读取；`src/time_axis.py` 的interval_end将00:10对应到00:00—00:10。候选Excel保留原位置，导致物理区间与显示标签晚10分钟的差异。

年度模板中，BI1是10:00—10:10，BJ1是10:10—10:20；当前内部物理10:00—10:10的值按位置写入BJ列。这个差异已在旧候选说明中披露，但披露不等于完成最终语义验收。

## 功率转电量必须注明近似

真正的时段电量是区间内功率积分。若只有时点值，可以声明使用左端保持、右端保持或线性插值积分等离散假设：

- 左端保持：`E[t,t+10min] ≈ P(t)/6`。
- 右端保持：`E[t,t+10min] ≈ P(t+10min)/6`，这是当前候选的数值口径。
- 线性插值积分：`E[t,t+10min] ≈ (P(t)+P(t+10min))/12`。

只有在输入本身是对应区间平均功率时，乘1/6才是直接的平均功率换算。本次原文不足以确认这一前提，也不足以确认“必须用梯形法”。价格代表哪一时段、是否区间保持，必须单独定义，不能机械套用负荷/PV的插值规则。

附件1的6:00、8:00等位置存在价格/负荷变化，可作为时点解释的线索，不能单凭跳变反推出官方的区间规定。

## 为什么不能只循环移位

按模板字面，它覆盖00:10到次日00:10；按题面日边界，模型覆盖00:00到24:00。两者差异涉及缺失的首区间和多出的次日区间。年度数据如需某日00:00时点，可考虑使用前一日24:00的同一物理时点，必须保留跨日来源；不得把本日未来24:00偷作本日已知00:00。

特别需要处理2025-01-01缺少前一日数据，以及输出最后一日延伸到2026-01-01首10分钟的问题。Q1的每天重复条件也不能不加说明地套到年度实际数据。更换区间口径后，6/12/18更新边界、四小时统计、紧急购电区间、价格映射及日终约束都要一起核对。

## 下一步调整范围

把时间语义统一移到最终导表之前的第一项收尾：先明确输入采样近似、日界与模板映射；在副本上检验候选解释的影响，再统一生成论文表与Excel。普通正文可继续写，最终时间表和费用封版需等待该项解决。现有129项测试证明既定候选实现的数值/因果一致性，不证明官方语义唯一正确。

在没有明确依据前，不直接改官方模板，也不把输入/输出循环移一格后宣称修复完成。所有后续重算应单独保存版本，不能把时间语义变化算作算法优化收益。
