## 参数—费用曲面

- `q2_cost_response_3d.pdf`、同名PNG：左侧是三维费用响应面，底部投影等高线；右侧是同一网格的二维等高线。
- 横轴：分位数水平 τ（0.50至0.90，步长0.05）；纵轴：裕量系数 κ（0.25至1.25，步长0.125）；高度/颜色：一月15至31日17天总费用。
- 全部81个节点实际计算，共1377次日回放。使用原B0严格执行器和因果残差历史，效率、终端、价格与之前开发期一致。
- 原参数(0.8,1.0)费用930672.15元；新密网格最低点(0.9,0.75)费用929199.21元。这是对已知开发期追加的描述性敏感性，**没有重新选取全年策略，不意味着全年可节省1472.94元，也不证明连续参数空间全局最优**。
- 网格之间只作曲面连接与等高线插值，插值处不是额外运行结果。主候选仍为原参数。
- 明细：`response_grid.csv`；实验来源：`analysis/q2_january_surface_v1/`，包含协议、压缩逐日轨迹、结果与独立物理/费用复算。8个旧参数组合费用复现差为0。

## 日内—月份储电量曲面

- `q2_soc_monthly_3d.pdf`、同名PNG：横轴物理时刻、纵轴月份、高度为月内逐时点日均储电量。
- 来源为既有B2的334天实际控制轨迹，共11×145个统计节点。每月内部各日等权平均；月份之间的连接仅用于观察图形，曲面本身不是某一天可执行的调度。
- 日初和日末均为6 MWh，平均值满足1.2至10.8 MWh物理界限。
- 明细：`soc_monthly_grid.csv`与`soc_manifest.json`。

## 制作方法

Matplotlib的`plot_surface`生成曲面；`plot_wireframe`/网格边线表达采样结构；`contour`投影等高线；`contourf`生成配套二维图；`set_proj_type('ortho')`与`view_init`控制视角。A面当前使用`view_init(elev=26, azim=50)`，让响应面的凹侧朝向观看者；这只改变观察方向，不改变参数网格、结果或颜色编码。使用同一颜色范围对应曲面和投影。不需要Blender，不能从参考截图断言原作者实际使用的软件。

脚本：`scripts/paper/build_3d_surface.py`、`scripts/paper/build_soc_3d.py`。第一个脚本已有结果时仅验证并重画，不覆盖实验结果。
