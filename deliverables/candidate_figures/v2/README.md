# V2 科研组图

[独立图册 PDF](research_figures_v2.pdf)包含5页组图、20个子图；每组另有PDF、PNG及图形数据JSON。所有图来自现有数据和冻结结果，本轮没有重跑优化或用全年表现重新选参数。

| 文件 | 图组 | 解释边界 |
| --- | --- | --- |
| `annual_patterns` | 全年三张热力图＋季节分位带 | 日期×时刻，无地理空间；阴影是经验分布，不是置信区间 |
| `margin_mechanism` | 山脊图＋实测参数网格＋历史裕量热力图＋费用瀑布 | 一月残差图是描述统计；八个参数组合无插值；实际每日裕量另列 |
| `dispatch_mechanism` | 净负荷预测、充放电/应急、SOC可达区、月时段应急矩阵 | 示例日固定选题面6月21日；日均应急包括零值日 |
| `strategy_stability` | 逐日成对散点、小提琴、累计收益、应急费用尾部 | 334天配对；不声称独立显著性检验 |
| `gate_decisions` | 门控成本边界、估计/事后对照、发布时间选择、月度净收益 | 事后固定延续反事实时域重叠，不能累加；仅月度总账表示实际策略收益 |

当前物理时间口径仍为右端采样候选，官方Excel映射未封版。Q2为B2，Q3对照裕量固定与门控。PDF中线条和文字可缩放，热力图是按真实矩阵嵌入的图像，不宣称整个PDF都是矢量图元。

脚本：`scripts/paper/build_research_figures.py`；依赖项目NumPy、SciPy、Matplotlib及本机Arial Unicode中文字体。`manifest.json`登记源文件与图件摘要，`*.data.json`提供各图的可复核数值。
