# 实验档案索引

`analysis/` 保存每一轮实验的原始结果、独立复核和轨迹证据。**目录路径、文件名和内容都不移动、不改写**：论文、脚本和多处哈希清单直接引用这里的路径，移动会同时破坏引用与可追溯性。需要修订时另建新版本目录，不覆盖旧证据。

按用途分四类。"主候选"指当前论文正文采用的结果。

## 读取约定

每个目录的 `result.json` 是主结果，同名 `*_validation.json` 或 `verify_*` 输出才是独立复核结论。主文件里的状态字符串可能仍写"待独立验收"，**以绑定的复核文件为准**。带 `source_sha256` / `code_sha256` 的清单记录了产出当时的输入与代码哈希，用于判断结果是否仍与当前代码对应。
